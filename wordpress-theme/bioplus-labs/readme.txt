Research-laboratory storefront theme for WooCommerce and Elementor — the biopluslabs.co.uk design.

== Description ==

A WordPress + WooCommerce build of the BioPlus Labs storefront: video hero, research catalogue with vial options, product
pages with research data, cart drawer, direct bank transfer checkout with a payment window and screenshot upload, the dark
"Research Hub" account area with Files & COA, the Certificates of Analysis batch register, the peptide dosage calculator,
the research-access age gate, a Forms inbox for every lead, and 26 Elementor widgets.

== Installation ==

1. Upload and activate the theme.
2. Install WooCommerce (required) and Elementor (recommended).
3. Appearance → BioPlus Setup → Run setup.

Full documentation: README.md in the theme's repository.
